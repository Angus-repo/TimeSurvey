🗓 怎麼選調查日期範圍
預設已幫你選好「明天起共 7 天」，你也可以自己重選：
• 再點一次起日或迄日，會取消目前的選取、重新開始。
• 重新選時，先點一個日期當起日，再點另一個日期當迄日，中間整段就是調查範圍。
• 點範圍中間的某一天，會把那天挖空，代表調查會跳過該天不排。
